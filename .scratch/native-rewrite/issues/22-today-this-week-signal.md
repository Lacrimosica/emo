# 22: TODAY / THIS WEEK from Reminders

**What to build:** Respect the user's TODAY and THIS WEEK subdivisions (weekly/daily goals) when planning.

**Blocked by:** 17

**Status:** needs-info

They're sections inside a Reminders list, and EventKit has no API for sections, so Emo can't see them.
Options for the user: flag = today; a due date (today / this Sunday); a `#today` / `#week` tag in the title or notes;
or separate `TODAY` / `THIS WEEK` lists. Emo would then boost priority (today = must plan today, this week = before Sunday).
